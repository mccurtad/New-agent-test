# Courses

One folder per course, named by course code (e.g. `BAN6303/`). Each folder
holds that course's syllabus, course map, modules, rubrics, and assignments,
plus a `course.md` recording the course name, code, and level or tone notes.

`/course-architect` creates a folder the first time you use it for a new
course, and the subagent only reads and edits the folder for the course named
in the current chat.
