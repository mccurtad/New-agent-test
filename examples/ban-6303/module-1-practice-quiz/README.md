# Module 1 Practice Quiz (QTI)

A working example of the [QTI generation method](../../../.claude/skills/course-architect/references/qti-quiz-generation.md):
an ungraded practice quiz built to reinforce Module 1's four MLOs, with
feedback baked in.

- `BAN6303_Module1_Practice_Check.zip` — ready to import into Canvas
  (Settings → Import Course Content → "QTI .zip file"). See the parent doc
  for how to get a native New Quizzes import instead of a Classic Quiz.
- `imsmanifest.xml`, `ban6303_mod1_practice/` — the unpacked source, useful as
  a template for building your own.

**Items:**
1. Rules-Based Programming vs. Machine Learning — Matching (stand-in for
   Categorization)
2. Supervised vs. Unsupervised Learning — Matching
3. Business Problem → ML Task — Multiple Dropdowns
4. Sequence the ML Workflow — Matching (stand-in for Ordering)

As with any generated QTI package: import into a sandbox course and click
through every question before using it for real.
